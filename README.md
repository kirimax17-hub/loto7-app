# iPhone用 ロト7 PWA

これはSafariで開いて「ホーム画面に追加」できるWebアプリです。

## 主な機能
- みずほ銀行の公開ロト7結果をサーバー側で取得
- 過去全期間 + 直近100回の出現率を混ぜて30通り生成
- 過去1等の完全一致組み合わせを除外
- 生成した30通りをiPhoneのブラウザ内に保存
- 次回抽せん結果と自動照合
- 3〜7個一致の件数を累計
- 等級判定
- 1口300円として累計購入額を記録
- 当選額を入力すると累計当選額・収支を自動計算
- PWA対応。Safariの「ホーム画面に追加」でアプリ風に起動

## 一番簡単な公開方法：Render
1. GitHubにこのフォルダ一式をアップロード
2. Renderにログイン
3. New + → Blueprint
4. GitHubリポジトリを選択
5. `render.yaml` が自動認識されるので作成
6. 発行された `https://xxxx.onrender.com` をiPhoneのSafariで開く
7. Safariの共有ボタン → 「ホーム画面に追加」

## iPhoneでの毎週の使い方
抽せん前：
1. 「① 公式結果を更新」
2. 「② 次回30通り」

抽せん後：
1. 「① 公式結果を更新」
2. 自動照合（または「③ 当選結果と照合」）
3. 当選があれば「当選額を入力」

## データ保存について
購入履歴や収支はiPhoneのSafari内の localStorage に保存します。
Safariのサイトデータを削除すると消えるため、長期利用では将来的にクラウド保存へ拡張するのがおすすめです。

## 注意
公平な抽せんでは、頻出数字を使うことや過去1等組み合わせを除外することが、次回1等の数学的確率を高める保証はありません。
